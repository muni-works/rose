# body

The rose humanoid: mini (100 cm, 22 DoF) and a full-size variant in the same design
language, on RobStride actuators, with the cortex head from [`../head`](../head).
Joint layout follows the Booster K1; structure is router-cut 3.2 mm aluminium
plates inside printed skins.

## Sources

The scripts form one flat Python package: run them from this folder.

| file | what it does |
|---|---|
| `k1_design.py` | The look: a rounded housing round each joint, bones lofted between them. |
| `k1_structure.py` | The structure: plates, actuator mounts and shells, for `mini` and `full`. |
| `design.py` | Industrial-design rules over the packaging. |
| `quad.py`, `leg.py`, `body.py` | Actuator data and the leg geometry the humanoid was built from (they began as a quadruped leg). |
| `k1.py`, `k1_teardown.py` | Booster K1 reference: its URDF and meshes, read from `~/Developer/booster_assets`. |
| `vcad_export.py` | Exports mini and full to vcad as loon assemblies, in [`vcad/`](vcad). |
| `rom_mini.py` | Range-of-motion sweeps: where each joint first collides. |
| `harness_check.py` | Every cable run clears every part, at rest and across head motion. |
| `hand_grasp.py`, `duet.py`, `walk_keys.py` | Hand closing on a can, the two-arm bench duet, and a walk animation from a K1 hardware trace. |

[`SHOULDER.md`](SHOULDER.md) is the shoulder design note.

## Outputs

- [`fab/`](fab): the mini v1 fab package (plates, shells, BOM, checks). Generated by
  `fab/make.py`; see its README before cutting anything.
- [`vcad/`](vcad): the loon assemblies. Generated by `vcad_export.py`. The committed
  export dates from 2026-10-21 and is older than the sources (2026-10-28):
  re-running it changes the mini's soles and some covers.
- [`renders/`](renders): `body-node/` is the current pass (2026-10-28); `lineup/` puts
  mini, full and mega side by side at scale; `neck/`, `torso-v103/` and `deep-mini/`
  are earlier passes on the neck, torso and a deeper mini.

```bash
uv run --with numpy --with trimesh --with manifold3d --with scipy --with shapely \
  --with ezdxf --with matplotlib --with scikit-image python vcad_export.py
```
